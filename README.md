
# **A Tetris Remake**  

This project is *Tetris* remake based on SDL2 based game, designed and developed by a 11th-grade student from **ITI "G. Marconi"** in Pontedera, Italy.  

The development was carried out as part of a school project under the guidance of **Prof. Stefano Lenzi**.  

## **About the Project**  

- **Engine:** Hand made based on SDL2  
- **Developer:** 11th Grade Student  
- **School:** ITI "G. Marconi" – Pontedera, Italy  
- **Coordinator:** Prof. Stefano Lenzi and Prof. Giuseppe Lombardi  

The main goal of the project was to face real life issues while developing a real-project: shareing codebase, defining a common goal, and respecting deadline (the result was shown during the Happy Hour, an science festival held at ITI 'G. Marconi')
